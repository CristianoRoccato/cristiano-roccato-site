SITO PERSONALE CRISTIANO ROCCATO

1. Apri index.html per vedere il sito in locale.
2. Prima della pubblicazione sostituisci in index.html:
   - INSERISCI-LA-TUA-EMAIL con l'indirizzo email desiderato.
   - Facebook / Instagram / YouTube con i link reali.
   - i riquadri segnaposto con fotografie e video.
3. Pubblicazione gratuita consigliata: GitHub Pages.
   Crea un repository, carica index.html, style.css e script.js, quindi abilita Pages nelle impostazioni del repository.

Il sito e' responsive per computer, tablet e smartphone.
